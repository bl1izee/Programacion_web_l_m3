# Porgramacion_web_l_m2

Misión M2 · Async Odyssey

## Cómo probarlo
Clona el repositorio y accede a la carpeta del proyecto, instala las 
dependencias con:

```bash
npm install
```

y arranca el servidor de Vite:

```bash
npm run dev
```

Abre la página por el puerto local que te proporciona y a jugar!

## Uso de IA
Se ha utilizado ChatGPT como apoyo para resolver dudas, analizar errores y 
revisar posibles mejoras. Las propuestas se revisan y prueban antes de 
incorporarlas al proyecto.
